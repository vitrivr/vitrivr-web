# frontend-vitrivr
React frontend for the vitrivr engine developed by the DBIS research group of the university of Basel. 

1. **Navigate to the frontend directory**  
   ```bash
   cd frontend/vitrivr
2. Install all of the dependencies:
   ```bash
    npm install
3. Build the app: 
   ```bash
    npm run build
4. Run the app: 
   ```bash
    npm run dev
